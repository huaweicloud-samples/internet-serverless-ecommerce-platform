## 简介

本项目是基于华为云构建的完整无服务器（Serverless）电商平台解决方案，该平台采用微服务架构设计，将每个业务模块独立部署为无服务器函数，通过 APIG 统一对外提供 RESTful API 服务。整个平台具备高可用、高弹性、按量结算的特点，能够根据业务流量自动扩缩容。

### 核心功能模块

本电商平台包含完整的电商业务功能，覆盖从用户注册到订单完成的全流程：

1. **用户认证模块** - 提供完整的用户生命周期管理功能，包括用户注册、登录登出、密码找回、Token 刷新等。认证模块采用自建 JWT 方案，用户数据存储在 RDS MySQL 中，支持多因素认证（MFA）可选功能。系统还提供用户权限管理，支持管理员和普通用户两种角色。

2. **商品管理模块** - 商家可通过后台管理商品信息，包括商品名称、价格、库存、描述、图片等属性。商品管理支持分类管理、标签管理、商品属性自定义等功能。系统提供商品搜索、商品推荐、商品评价等增值服务，帮助提升用户购物体验。商品数据存储在 RDS MySQL 中，支持灵活的查询和筛选。

3. **订单处理模块** - 负责处理用户下单、订单支付、订单履约等核心流程。订单模块与库存模块联动，下单时自动扣减库存，订单取消时自动回滚库存。订单状态包括：待支付、已支付、已发货、已完成、已取消等多种状态，支持订单状态变更回调通知。

4. **支付模块** - 集成华为云支付网关，支持多种支付方式（包括微信支付、支付宝、银联等）。支付模块提供支付下单、支付回调、支付查询、退款等接口。支付安全通过 KMS 密钥管理服务保障，所有交易敏感信息加密存储。

5. **库存管理模块** - 实时管理商品库存数量，支持库存预警、低库存提醒、库存锁定等功能。库存模块与订单模块紧密配合，确保超卖和少卖情况的发生。系统支持多仓库库存管理，可根据用户地址智能分配发货仓库。

6. **配送服务模块** - 集成多家快递物流服务，提供运单生成、物流追踪、签收确认等功能。配送模块支持多种配送方式（标准快递、加急配送、同城配送等），可根据用户选择和商品属性自动匹配最优配送方案。

### 技术架构特点

- **微服务架构**：每个业务模块独立部署，独立扩缩容，故障隔离
- **无服务器计算**：使用 FunctionGraph，按请求量结算，无需预置资源
- **事件驱动**：通过 EventGrid 实现模块间的事件通信，提高系统响应速度
- **数据一致性**：使用分布式事务保证跨模块数据一致性
- **安全合规**：通过 KMS 实现敏感数据加密，符合电商安全规范

## 快速开始

### 1. 配置凭证

```bash
export HW_ACCESS_KEY="your-access-key"
export HW_SECRET_KEY="your-secret-key"
```

### 2. 初始化 Terraform

```bash
cd infra
terraform init
```

### 3. 部署

```bash
terraform apply
```

## 使用方法

### 调用 API

```bash
# 用户注册
curl -X POST https://{apig-url}/auth/register \
  -H "Content-Type: application/json" \
  -d '{"username": "user1", "password": "pass123"}'

# 用户登录
curl -X POST https://{apig-url}/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username": "user1", "password": "pass123"}'

# 获取商品列表
curl https://{apig-url}/products

# 创建订单
curl -X POST https://{apig-url}/orders \
  -H "Content-Type: application/json" \
  -d '{"user_id": "user123", "items": [{"product_id": "1", "quantity": 2}]}'
```

## 清理资源

```bash
terraform destroy
```

## 详细说明

### 微服务架构

平台包含以下微服务：

1. **用户服务 (users)** - 用户认证和管理
2. **商品服务 (products)** - 商品查询
3. **订单服务 (orders)** - 订单创建和处理
4. **仓库服务 (warehouse)** - 库存管理
5. **配送服务 (delivery)** - 配送处理
6. **配送结算服务 (delivery-settlement)** - 运费计算
7. **支付服务 (payment)** - 支付处理

### 事件驱动

订单创建后，EventGrid 自动触发后续服务：
- 订单创建 → 仓库服务 → 配送服务 → 支付服务
