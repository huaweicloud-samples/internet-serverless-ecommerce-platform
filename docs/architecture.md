# 架构说明：无服务器电商平台

## 概述

本文档描述华为云上的无服务器电商平台架构，实现完整的电商功能。

## 系统架构

```

├─────────────────────────────────────────────────────────────────────────┤
│                                                                         │

│  │                         APIG (API 网关)                         │  │
│  │  /auth/* → /products → /orders → /payment → /delivery/*       │  │
│  └────────────────────────────────────────────────────────────────┘  │
```

## 组件说明

### 1. API 接入层

| 组件 | 用途 |
|------|------|
| APIG | 统一 API 网关，路由到各个微服务 |

### 2. 计算层

| 服务 | 用途 |
|------|------|
| users-auth | 用户认证（JWT） |
| products-api | 商品查询 |
| orders-api | 订单管理 |
| warehouse-api | 库存管理 |
| delivery-api | 配送处理 |
| delivery-settlement | 运费计算 |
| payment-api | 支付处理 |

### 3. 数据层

| 组件 | 用途 |
|------|------|
| RDS MySQL | 关系型数据库 |
| OBS | 对象存储（静态资源）|

### 4. 事件层

| 组件 | 用途 |
|------|------|
| EventGrid | 事件驱动编排 |

## 数据流

1. 客户端 → APIG → FunctionGraph
2. FunctionGraph → RDS MySQL 读写数据
3. 订单创建 → EventGrid → 触发后续服务
4. 仓库 → 配送 → 支付（事件驱动）

## 安全

- JWT Token 认证
- APIG 自定义认证
- KMS 密钥管理
- VPC 网络隔离
